# Sirr Community Code of Conduct

Treat contributors and users respectfully regardless of language, background, identity, experience or ability. Make participation accessible to Arabic- and English-speaking contributors.

Discuss ideas with evidence. Ask clear questions, assume good intent when reasonable, acknowledge mistakes and critique the work without attacking the person. Do not harass, threaten, discriminate, publish another person's private information, or post sexual or abusive content.

Maintainers may request edits, remove harmful material, close disruptive threads or limit participation proportionately. They should explain moderation decisions when doing so does not expose private information. Maintainer status does not exempt anyone from this policy.

For ordinary non-sensitive conduct concerns, contact the repository owner through an available GitHub channel. A dedicated confidential moderation contact has not yet been published and must be established as the community grows. Do not post personal details publicly to report a concern. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This policy covers repository issues, pull requests, reviews and project discussions, as well as official project spaces established later. It does not grant access to private devices or accounts.
